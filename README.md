### 🍪 Mukies Cookies

Web API desenvolvida para auxiliar pequenos vendedores de cookies no **gerenciamento de produtos e pedidos**.

O sistema permite cadastrar categorias e produtos, definir preços, controlar disponibilidade e registrar pedidos com seus respectivos itens.

**Tecnologias**

`C#` `.NET 8` `Entity Framework Core` `SQL Server`

**Recursos**

- Cadastro de categorias
- Cadastro de produtos
- Gerenciamento de pedidos
- Itens de pedidos
- CRUD completo
- Relacionamentos entre entidades
- Filtros de pesquisa
- Persistência com Entity Framework Core

<br>
